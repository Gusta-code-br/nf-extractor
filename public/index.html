RAG Simples

              
Converte sua pergunta em SQL e consulta o banco de dados diretamente. Ideal para perguntas diretas sobre registros.

            

            

              

              
RAG Embeddings

              
Busca semântica por similaridade vetorial nos dados indexados. Ideal para perguntas contextuais e análises.
